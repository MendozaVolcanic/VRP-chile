Acerca de VRP Chile

VRP Chile es un sistema independiente de monitoreo térmico satelital para volcanes chilenos, construido sobre la metodología del sistema MIROVA (Middle InfraRed Observation of Volcanic Activity) desarrollado por el grupo de Diego Coppola y colaboradores en la Università di Torino.

Métricas de desempeño (S73 — deriva S26→S71 validada por 3 fuentes independientes)

Algoritmo operacional acumulado: drift234 (Coppola 2016a Tests 2∧3 + dual-ROI + second-pass) + kernel local 3×3 background (Coppola 2024 L1129) adoptado per-vol S61-S65 + cap path D dNTI ctx 5 MW (S71) + saturation guard L1B sentinel filter (S73 F2.8, en PR).

Clon literal logrado: 7 / 9 volcanes Tier A con ratio mediano ≤ 3× MIROVA NRT (audit ALERTAS reales CONS+OCR ~80d):
  • Lascar 1.37×, Isluga 1.33× — calibrados natural (sin fix necesario)
  • Lastarria 1.07× ✓ (S62, R2 pixel-level validado: drift TIF 0.75 km), PCC 0.29× ✓ (S63)
  • Villarrica 2.17× (S61), Chaiten 2.23× (S63), PP 2.84× (S61)
  • Tupungatito S65 fix mirova_center: 56 % records con cluster cráter real correcto (43 % aún en cluster selection residual, S69+)
  • Llaima / Copahue / NdC: n baja (esperar más actividad MIROVA)
Validación deriva S26→S71 (S72) — confirmada por 3 fuentes independientes:
  • AVTOD ASTER (Reath et al. 2019, Coppola coautor): Tupungatito identificado FP MIROVA, régimen Muy Bajo justificado físicamente
  • MIROVA NRT CONS + OCR (F2.6.h): 16/16 records "lost summit >500 MW" inflados 1000× sobre MIROVA NRT (mediana 1910×) — confirma que features S38-S71 son mejora, no regresión
  • Geográfico Salar Atacama (F2.6.g): 67 % "lost summit far" en zona Salar — eran FPs, no detecciones reales
F2.8 saturation guard (S73, en PR #133): identificado MODIS L1B sentinel filter incompleto (solo enmascarábamos 65535 de los 14 sentinels Tabla 5.6.1) y VIIRS quality_flags SDS no leído. Causa raíz del record patológico PP 2026-03-18 pc.vrp_mw=695,431 MW: 113 pixels saturados pasaron calibración estándar produciendo BT=575 K extrapolado. Fix: 1 línea MODIS + lectura quality_flags VIIRS. Match matemático 99.86 % con record observado.

Adopciones operacionales: 5 vols con local_kernel_bg=true (Villarrica/PP/Lastarria/Chaiten/PCC). Cron NRT cada 2h aplica fix automáticamente; pages-deploy tolerante a fails parciales (PR #87).
Universo de referencia: CSV consolidado + OCR (Mirova-v1, 17 966 + 476 records). Comparación con pc.vrp_mw (primary_cluster summit) vs MIROVA VRP_MW. Ratios match-only en ALERTAS específicas; records RUTINA-MIROVA sub-publicados pueden aparecer como sobre-detección. Ver HYPOTHESIS_LOG para 28+ hipótesis acumuladas S60-S73 + F28_SATURATION_INVESTIGATION (S73).
