## (d) Propuesta de formato de localizador

Un comentario por párrafo, con **un localizador por afirmación**, que reemplace las líneas de `.txt`:

```

```

Campos fijos, separados por `|`: identificador, cita corta, archivo PDF, página impresa con visor,
sección y párrafo (o figura, tabla o ecuación) y una frase ancla verbatim de hasta 25 palabras
para buscarla con Ctrl+F. La frase ancla es la que permite comprobar la cita a mano aunque la
paginación del PDF no coincida.

Al pie de cada sección, una tabla "Localizadores" con las mismas columnas, para que el revisor
compruebe todo sin abrir el `.md`:
