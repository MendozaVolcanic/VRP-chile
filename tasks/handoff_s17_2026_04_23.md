## Lecciones operacionales S15-S16 nuevas

**A11 — Skills DEBEN invocarse antes de actuar**: pasamos varias horas
proponiendo fixes sin systematic-debugging. Cuando lo invocamos para H1,
encontramos el commit culpable en 5 minutos. **Costo de no invocar = horas
perdidas en hipótesis incorrectas**.

**A12 — Bbox + nada filtro = catástrofe**: ampliar ROI sin filtros físicos
de cuerpos de agua/salares = FPs masivos. Lección: cualquier expansión
geométrica del ROI debe venir junto con un filtro contextual.

**A13 — Reprocesos paralelos > secuenciales con tiempo limitado**: 3 procesos
en paralelo en 9h = 24-27 días-volcán. 1 secuencial = 9 días. Siempre
paralelo cuando hay >1 volcán a procesar.

**A14 — n_dnti_ctx_path UnboundLocalError**: variables inicializadas dentro
de bloques condicionales pueden fallar si el bloque no se ejecuta. Lección:
inicializar todas las variables del output dict ANTES de cualquier
condicional. Patrón aplicable: revisar otros sitios similares.

**A15 — git show es más confiable que mi memoria**: usé git show para extraer
config S9 exacta y diff vs S15. Evidencia ground truth invaluable.
**Nunca fiarse de "creo que en S9 era así"**.
